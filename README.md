# Retail Sales Forecasting Using Machine Learning

## Project Overview
This project predicts retail store sales using Machine Learning. It uses store information, dates, promotions, and holidays to estimate sales.

## Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML
- CSS
- JavaScript
- Chart.js

## Project Features
- Enter Store ID and date.
- Select promotion and holiday details.
- Predict retail sales.
- Display predicted sales on a dashboard.
- View sales predictions in a chart.
- Track total predictions and total predicted sales.

## Project Structure
- `app.py` – Flask application
- `train_model.py` – Model training script
- `templates/index.html` – Dashboard interface
- `requirements.txt` – Python dependencies
- `.gitignore` – Files excluded from GitHub

## How to Run
## How to Run

1. Install the required libraries:
   pip install -r requirements.txt

2. Train the machine learning model:
   python train_model.py

3. Start the Flask application:
   python app.py

4. Open http://127.0.0.1:5000 in your browser.
